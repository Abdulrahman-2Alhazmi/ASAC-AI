# 🤖 ASAC AI Model

ASAC AI Model is the backend intelligence of the ASAC Voice Assistant project. It captures the user's speech, converts it into text, sends the request to the Cohere AI model, receives the response, and converts it back into speech.

The system supports **both Arabic and English**, automatically detecting the user's language and responding in the same language using the appropriate voice.

---

## ✨ Features

- 🎤 Speech-to-Text (Voice Recognition)
- 🤖 AI Response Generation using Cohere
- 🔊 Text-to-Speech
- 🌍 Automatic Arabic & English Language Detection
- 🎙️ Different voices for Arabic and English responses
- 💻 Console-based AI backend

---

## 🛠️ Technologies Used

- Python
- Cohere API
- Whisper
- RealtimeSTT
- Edge-TTS
- SoundDevice
- SoundFile
